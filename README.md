# 🚀 Landing Page — Projeto de Treino

Projeto desenvolvido durante meus estudos de **HTML5**, com o objetivo de praticar a criação e estruturação de uma Landing Page do zero.

## 📌 Sobre o projeto

Esta Landing Page foi criada como um projeto de **treino em HTML**, colocando em prática os conhecimentos adquiridos durante meus estudos de desenvolvimento web.

O foco principal foi aprender a estruturar corretamente uma página utilizando os elementos e recursos disponíveis no **HTML5**.

## 🛠️ Tecnologia utilizada

* **HTML5**

> Este projeto foi desenvolvido utilizando somente HTML, sem CSS ou JavaScript.

## 🎯 Objetivos

* Praticar HTML5
* Aprender a estruturar uma página web
* Utilizar elementos semânticos
* Organizar melhor o código HTML
* Desenvolver uma Landing Page do zero
* Colocar em prática conceitos aprendidos nos estudos

## 📂 Estrutura

```text
landing-page/
│
├── index.html
└── README.md
```

## 📚 Aprendizados

Durante o desenvolvimento, pratiquei conceitos como:

* Estrutura básica do HTML
* Títulos e parágrafos
* Links
* Imagens
* Listas
* Seções
* Formulários
* Elementos semânticos
* Organização e indentação do código

Este projeto representa uma das etapas da minha evolução na programação.

Nos próximos projetos, pretendo começar a aplicar **CSS** para trabalhar o design e, posteriormente, **JavaScript** para adicionar interatividade às páginas.
